# NFT Marketplace Metadata API - Basic Endpoints
# Base URL: https://api.zuno-marketplace.com/v1

## AUTHENTICATION
# Header: X-API-Key: <your_api_key>
          X-API-Version: v1.0.0


## API ROUTER CAN USING ? PARAMETERS IF NEEDED

## Basic CRUD
GET    /metadata                     # List all metadata
POST   /metadata                     # Create new metadata
GET    /metadata/:id                 # Get metadata by ID
PUT    /metadata/:id                 # Update metadata
DELETE /metadata/:id                 # Delete metadata


## Batch Operations
GET    /metadata/batch               # List all metadata in batch
POST   /metadata/batch               # Create new metadata in batch
PUT    /metadata/batch               # Update metadata in batch
DELETE /metadata/batch              # Delete metadata in batch


## Basic CRUD
GET    /media                        # List all media
POST   /media                 # Upload media file
GET    /media/:id                    # Get media by ID
DELETE /media/:id                    # Delete media

## Batch Operations
POST   /media/batch           # Bulk upload media files
DELETE /media/batch                 # Bulk delete media
